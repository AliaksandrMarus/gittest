# Сюда кладутся фотографии

Компонент `Photo` ищет файлы по именам из [../../ASSETS.md](../../ASSETS.md).
Пока файла нет, на его месте рисуется заглушка — сайт собирается в любом случае.

```
src/assets/
  uslugi/     шапки страниц услуг: <слаг-услуги>.jpg
  raboty/     галерея и пары «до/после»
  yandex/     сюда складывает скачанное scripts/fetch-photos.mjs
  wp/         сюда складывается медиабиблиотека старого сайта
```

Папки `yandex/` и `wp/` — промежуточные: из них выбираются лучшие кадры
и переименовываются в `uslugi/` и `raboty/`.
