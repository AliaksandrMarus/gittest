# Манипулятор Бобруйск — сайт (index.html + excavator.html)

Статический 2-страничный сайт на чистом HTML/CSS/JS, без сборки и без
npm-зависимостей. Независим от Astro-проекта `lighton.by`, который лежит в
корне этого репозитория, — папку `manipulator-bobruisk/` можно скопировать
и задеплоить отдельно на любой статический хостинг.

Две страницы с переключателем в шапке:

- `index.html` — аренда крана-манипулятора (КМУ)
- `excavator.html` — аренда мини-экскаватора с оператором

## Локальный просмотр

Открыть `index.html` напрямую в браузере (`file://`) в целом работает, но
для корректной проверки отправки формы нужен локальный сервер:

```bash
cd manipulator-bobruisk
npx serve .
# или
python3 -m http.server 8080
```

Затем открыть `http://localhost:PORT/`.

## Деплой

Сборка не требуется — просто скопируйте содержимое папки
`manipulator-bobruisk/` в корень любого статического хостинга:

- **Netlify / Cloudflare Pages** — перетащить папку в интерфейсе или указать
  её как каталог публикации (build command не нужен).
- **Обычный хостинг / FTP** — залить файлы как есть.
- **GitHub Pages** — отдельный репозиторий или отдельный workflow (этот сайт
  **не** подключён к существующему `.github/workflows/pages.yml`, который
  собирает только сайт lighton.by).

## Структура

| Путь | Назначение |
|---|---|
| `index.html` / `excavator.html` | Две страницы сайта, полностью самодостаточны (шапка, форма, футер продублированы в каждой) |
| `css/styles.css` | Общая тёмная дизайн-система: токены, компоненты, адаптивные брейкпоинты |
| `js/main.js` | Мобильное меню, фолбэк hero-видео на постер, FAQ-аккордеон, reveal-анимации, отправка формы через `fetch` |
| `video/` | Фоновые видео hero-блока (пока не сгенерированы) и постеры-заглушки — см. `VIDEO-PROMPTS.md` |
| `img/icons/` | Собственные line-иконки (услуги, телефон, WhatsApp, Telegram, Viber и т.д.) |
| `img/illustrations/` | SVG-иллюстрации техники для раздела «Наш автопарк» |
| `robots.txt`, `sitemap.xml` | Базовая техническая SEO-настройка на обе страницы |
| `site.webmanifest` | Иконки и метаданные для «Добавить на экран» |
| `ASSETS.md` | Полный список плейсхолдеров и что нужно заменить перед запуском |
| `VIDEO-PROMPTS.md` | Готовые промты для генерации фоновых видео в Seedance |

## Что нужно сделать перед публикацией

Подробности и таблицы — в [ASSETS.md](./ASSETS.md). Коротко:

- [ ] Сгенерировать и вставить фоновые видео по промтам из `VIDEO-PROMPTS.md`
- [ ] Заменить `REPLACE-WITH-DOMAIN.by` на реальный домен во всех файлах
      (canonical, OG, JSON-LD, `robots.txt`, `sitemap.xml`)
- [ ] Зарегистрировать форму на [Formspree](https://formspree.io/) (или
      аналоге) и заменить `REPLACE_WITH_FORM_ID` в обеих формах
- [ ] Проверить рабочие ссылки WhatsApp/Telegram/Viber на реальных
      устройствах — номер для звонков не всегда совпадает с мессенджерами
- [ ] Подставить реальные цены в раздел «Цены» вместо таблицы факторов
- [ ] Заменить SVG-иллюстрации техники на настоящие фото, когда появятся
- [ ] Добавить мета-теги подтверждения Яндекс.Вебмастера и Google Search
      Console, отправить `sitemap.xml` в обе панели
- [ ] Подключить Яндекс.Метрику / GA4 — `js/main.js` уже отправляет события
      `phone_click`, `messenger_click`, `lead_sent`, если счётчик появится
      в `<head>`

## Технические решения

**Почему две страницы, а не одна.** Каждая услуга (манипулятор и
мини-экскаватор) — отдельный кластер поисковых запросов. Раздельные
страницы с собственным `<h1>`, meta-тегами и JSON-LD ранжируются по своим
запросам лучше, чем один общий лендинг, при этом переключатель в шапке и
взаимные ссылки между страницами удерживают их как единый тематический
блок для поисковиков.

**Почему видео, а не сразу фото.** Реальных съёмок техники в работе нет.
Публиковать стоковое видео чужой техники под видом своей — тот же риск
потери доверия, что и с фото (см. `ASSETS.md`). Сайт поставляется с рабочей
вёрсткой `<video>` и аккуратным фолбэком на постер, а готовые ролики
подставляются по готовым промтам без правок кода.

**Почему без фреймворков.** Лендинг с двумя страницами не требует React/Vue
или сборщика — чистые HTML/CSS/JS грузятся мгновенно на любом хостинге,
не ломаются от обновления зависимостей и не увеличивают вес страницы
(в отличие от исходного сайта-конкурента на WordPress + Elementor +
Revolution Slider + jQuery, который и стал поводом переписать сайт с нуля).
