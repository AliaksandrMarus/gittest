# Fits — личный цифровой гардероб

Клон приложения Fits для личного пользования: PWA без сервера и сборки.
Все данные (фото, образы, календарь) хранятся только на устройстве, в IndexedDB браузера.

## Что умеет

- **Гардероб.** Фото вещи → автоматическое удаление однотонного фона → карточка:
  категория, тип, цвета (подсказываются по фото), бренд, размер, цена, дата покупки,
  сезоны, теги, заметки, избранное, архив. Поиск, фильтры по цвету и сезону, сортировки.
  Можно добавить сразу несколько фото или перетащить их на страницу (на компьютере).
- **Вырезание фона.** Нейросеть (аккуратно вырезает вещь на любом фоне), авто-фон
  с ползунком чувствительности (мгновенно, для ровного фона), «волшебная палочка»
  (нажать на фон), ластик и кисть «вернуть», отмена, поворот, возврат к исходнику.
- **Конструктор образов.** Холст 3:4: вещи двигаются пальцем, двумя пальцами —
  масштаб и поворот (на компьютере — колесо мыши, Shift+колесо, стрелки, Delete),
  слои выше/ниже, отражение, копия, фон холста. Кнопка «Случайно» собирает образ
  из вещей текущего сезона.
- **Лукбуки** — подборки образов.
- **Календарь.** Отметка, что надето (образ или отдельные вещи), планирование на будущее,
  заметки к дню, создание образа прямо для выбранной даты.
- **Статистика.** Стоимость гардероба, цена за выход, любимые вещи, ни разу не надетые,
  не надетые 3+ месяца, категории, цвета, активность за 12 недель.
- **Настройки.** Тема (системная/светлая/тёмная), валюта, резервная копия в JSON
  и восстановление из неё, защита хранилища от автоочистки.
- Работает офлайн, ставится на домашний экран как приложение.

## Запуск

Нужен любой статический сервер (модули и service worker не работают по `file://`):

```bash
cd fits
python3 -m http.server 8080
# открыть http://localhost:8080
```

На телефоне приложение должно открываться по HTTPS (иначе не будет офлайн-режима
и установки). Проще всего — GitHub Pages: workflow `.github/workflows/pages.yml`
кладёт папку в `/fits/` превью-сайта, адрес
`https://aliaksandrmarus.github.io/gittest/fits/`. Код приложения публичный,
но данные на сервер не уходят никогда.

Установка: iPhone — Safari → «Поделиться» → «На экран „Домой“»;
Android — меню Chrome → «Установить приложение».

## Как фотографировать

Автоудаление фона рассчитано на ровный фон: разложите вещь на однотонной поверхности,
контрастной по цвету (белая футболка — на тёмном полу, чёрная — на светлой простыне),
снимайте сверху при рассеянном свете. Остатки фона добиваются палочкой и ластиком.

## Нейросеть для фона

Модель IS-Net из библиотеки [@imgly/background-removal](https://github.com/imgly/background-removal-js)
версии 1.4.5, собранная в `vendor/bg-removal.js` (≈670 КБ, грузится только при первом нажатии
«Нейросеть»). Работает прямо в браузере: фото на сервер не отправляются.

- При первом запуске скачиваются движок ONNX (≈10 МБ) и модель: «Быстрая» ≈44 МБ
  или «Точная» ≈88 МБ (выбор в настройках). Источник — CDN `staticimgly.com`,
  запасной — `unpkg.com`. Service worker кладёт файлы в отдельный кэш, дальше всё работает офлайн.
- «Настройки → Удаление фона → Нейросеть» включает её для всех новых фото;
  иначе она доступна кнопкой в редакторе. Там же можно скачать модель заранее по Wi-Fi.
- Одно фото обрабатывается от нескольких секунд (компьютер) до ~полуминуты (слабый телефон).
- Версия данных модели жёстко связана с версией библиотеки: при обновлении
  `vendor/bg-removal.js` поменяйте версию в `js/ai-bg.js` и `AI_CACHE` в `sw.js`.
- Лицензия библиотеки — AGPL-3.0 (`vendor/LICENSE-imgly-background-removal.md`):
  для личного пользования подходит; если будете распространять приложение, его код
  тоже должен быть открыт.

Пересборка бандла:

```bash
npm i @imgly/background-removal@1.4.5 esbuild
echo "export { removeBackground, preload } from '@imgly/background-removal';" > entry.mjs
npx esbuild entry.mjs --bundle --format=esm --minify --platform=browser --target=es2020 \
  --legal-comments=eof --outfile=fits/vendor/bg-removal.js
```

## Резервная копия

Данные живут в браузере: при очистке данных сайта или смене телефона они пропадут.
Периодически делайте «Настройки → Резервная копия» — это один JSON-файл с фотографиями
внутри. «Восстановить» добавляет данные из файла (записи с теми же id перезаписываются).

## Устройство

| Файл | Что это |
|---|---|
| `js/store.js` | Состояние в памяти + запись в IndexedDB, статистика носки, бэкап |
| `js/db.js` | Обёртка над IndexedDB (items, outfits, plans, lookbooks, meta) |
| `js/image-tools.js` | Удаление фона (заливка от краёв), палочка, подсказка цвета |
| `js/ai-bg.js` | Удаление фона нейросетью: загрузка модели, источники, прогресс |
| `js/outfit-tools.js` | Раскладка вещей на холсте, случайный образ, рендер превью |
| `js/views/*` | Экраны: гардероб, вещь, редактор вещи, образы, конструктор, календарь, статистика, настройки |
| `sw.js` | Офлайн-кэш оболочки. После изменения списка файлов поднимите `CACHE` |
