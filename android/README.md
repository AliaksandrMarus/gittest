# «Мой гардероб» — Android-приложение

MVP: женщина фотографирует себя в полный рост, фотографирует свою одежду и
обувь (фон вырезается автоматически, определяется доминирующий цвет),
собирает из этого образы на холсте — вручную или по подсказке простого
правило-based «виртуального помощника». Kotlin + Jetpack Compose, без
бэкенда и без API-ключей.

Проект лежит в этой директории (`android/`) отдельно от сайта автомойки в
корне репозитория — они никак не пересекаются.

## Требования

- **Android Studio** — актуальная стабильная версия (Ladybug/Koala или новее).
  Скачать: https://developer.android.com/studio
- Свободно ~10 ГБ на диске (SDK, эмулятор, кэш Gradle).
- **Телефон на Android 8.0 (API 26) и новее** для установки и теста
  (эмулятор не подойдёт — приложению нужна настоящая камера).
- Компьютер с интернетом хотя бы на первую синхронизацию Gradle (скачивание
  зависимостей) — дальше можно работать офлайн.

## Шаг 1. Установить Android Studio

Стандартная установка (Standard) — она сама поставит Android SDK, платформу
Android 15 (API 35) и инструменты сборки. Ничего донастраивать вручную не
нужно, Android Studio сама предложит недостающее при первом открытии проекта.

## Шаг 2. Открыть проект

**Важно:** открывать нужно именно папку `android/` внутри репозитория, а
не сам репозиторий целиком — иначе Android Studio не найдёт Gradle-проект
(в корне репозитория лежит отдельный сайт на Astro, никак не связанный с
этим приложением).

1. Android Studio → **File → Open**.
2. Выбрать папку `<путь-к-репозиторию>/android`.
3. Дождаться завершения индексации и синхронизации Gradle (полоса
   прогресса внизу окна). При первой синхронизации будет скачано
   несколько сотен мегабайт зависимостей — нужен интернет.

### Если Android Studio попросит восстановить Gradle wrapper

В репозитории есть скрипты `gradlew`/`gradlew.bat`, но нет самого бинарного
`gradle-wrapper.jar` — такой файл нельзя было надёжно создать руками без
живого Gradle под рукой. При открытии проекта Android Studio обычно сама
предлагает восстановить обёртку (кнопка вроде «Try Again» / предложение
пересоздать wrapper) — просто соглашайтесь. Если не предложит сама:
**File → Sync Project with Gradle Files**, либо откройте встроенный
терминал Android Studio (Alt+F12 / View → Tool Windows → Terminal) и
выполните из папки `android`:

```
gradle wrapper --gradle-version 8.9
```

(нужен установленный где-то в системе Gradle — Android Studio обычно
включает свой; если команды `gradle` нет вообще, используйте пункт меню
Studio выше — он не требует системного Gradle).

## Шаг 3. Подготовить телефон

1. **Настройки → О телефоне** → несколько раз нажать на «Номер сборки»,
   пока не появится сообщение «Вы стали разработчиком».
2. **Настройки → Система → Для разработчиков** (или отдельный пункт
   «Для разработчиков» в главных настройках) → включить
   **«Отладка по USB»**.
3. Подключить телефон к компьютеру кабелем, **который передаёт данные**
   (не только заряжает — если сомневаетесь, попробуйте другой кабель).
4. На телефоне появится запрос «Разрешить отладку по USB с этого
   компьютера?» — подтвердить, отметив «Всегда разрешать с этого
   компьютера».

## Шаг 4. Запустить приложение на телефоне

1. В верхней панели Android Studio, рядом с зелёной кнопкой ▶ Run,
   в выпадающем списке устройств должен появиться ваш телефон по имени.
   Если не появился — см. «Проблемы» ниже.
2. Нажать зелёную кнопку **Run ▶** (или Shift+F10).
3. Android Studio соберёт APK, установит на телефон и запустит — на
   телефоне откроется приложение «Мой гардероб».

## Как пользоваться приложением

1. Вкладка **Профиль** → «Сделать фото» → сфотографироваться в полный рост
   (это фото станет фоном в конструкторе образов).
2. Вкладка **Гардероб** → кнопка «+» → сфотографировать вещь на светлом
   фоне → приложение само уберёт фон и определит цвет → выбрать категорию,
   сезон, повод → «Сохранить в гардероб». Повторить для нескольких вещей
   (важно иметь хотя бы что-то в категориях «Верх»/«Низ» или «Платье», а
   также «Обувь» — без обуви помощник не соберёт образ).
3. Вкладка **Образы** → «+» открывает конструктор: тяните вещи из ленты
   снизу на холст, двигайте/масштабируйте/поворачивайте пальцами прямо
   на фото, долгое нажатие на вещи — убрать с холста, галочка сверху —
   сохранить.
4. Там же на вкладке **Образы** — кнопка **«Подобрать образ»**: помощник
   предложит несколько вариантов из вещей в гардеробе с кратким
   объяснением; выбор варианта открывает его в конструкторе, где можно
   подправить и сохранить.

### Про первый запуск вырезания фона

Вырезание фона работает через Google Play Services (ML Kit Subject
Segmentation) — никакого отдельного аккаунта, API-ключа или
`google-services.json` для этого не нужно. При самом первом использовании
на телефоне Play Services может один раз незаметно скачать модель через
интернет; если в этот момент сети нет, вырезание фона на один раз
отработает как no-op (вернёт исходное фото без прозрачного фона) — это
ожидаемое поведение, а не баг, повторная попытка при наличии сети сработает
нормально.

## Типичные проблемы

| Проблема | Решение |
|---|---|
| Телефон не появляется в списке устройств | Переустановите/обновите USB-драйверы (Windows), попробуйте другой кабель с поддержкой передачи данных, проверьте, что отладка по USB включена и подтверждена на телефоне |
| Gradle sync падает с сетевой ошибкой | Проверьте интернет/VPN/файрвол — первая синхронизация качает зависимости из google() и mavenCentral() |
| Ошибка компиляции в конкретном файле | Пришлите текст ошибки — код написан и вычитан вручную (в этой среде нет Android SDK, чтобы прогнать настоящую сборку), поэтому если что-то всё же не собралось, это быстро правится точечно |
| Не удаётся установить APK («INSTALL_FAILED…») | Удалите предыдущую версию приложения с телефона вручную и запустите Run ещё раз |

## Технические детали (для контекста, не обязательно к прочтению)

- Kotlin 2.0.21, Jetpack Compose (BOM 2024.10.01), AGP 8.6.1, Gradle 8.9.
- minSdk 26, targetSdk/compileSdk 35.
- Room — локальная база (вещи гардероба, образы, размещение вещей на
  холсте). DataStore — для единственного значения (URI фото в полный рост).
- Все фото хранятся во внутренней памяти приложения — разрешения на
  внешнее хранилище не требуются, только `CAMERA`.
- Ручной DI-контейнер (`di/AppContainer.kt`) вместо Hilt — осознанный выбор
  для этого масштаба проекта, см. код.
- `BackgroundRemover` и `OutfitAdvisor` — интерфейсы с единственной MVP-
  реализацией каждый; обе точки специально оставлены заменяемыми (облачное
  вырезание фона, LLM-советчик) без изменений в остальном коде.
