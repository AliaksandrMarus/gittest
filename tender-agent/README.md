# ТендерАгент

Программа для Windows. Следит за тендерами Беларуси, сверяет их с вашим прайсом и готовит
пакет документов для ценового предложения. Подписываете ЭЦП и подаёте предложение вы сами.

Работает **без VPN**. Программа обращается только к белорусским площадкам:
icetrade.by, goszakupki.by, zakupki.butb.by. Сверка с прайсом и заполнение документов
выполняются на вашем компьютере, без интернета и без зарубежных сервисов.

## Как установить

1. Откройте страницу **Releases** этого репозитория на GitHub и скачайте `TenderAgent.exe`
   из последнего выпуска.
2. Запустите файл. Если Windows покажет «Windows защитила ваш компьютер», нажмите
   «Подробнее» → «Выполнить в любом случае». Окно появляется, потому что у программы
   нет платной цифровой подписи.
3. Если хотите, чтобы программа запускалась быстрее, скачайте `TenderAgent-folder.zip`,
   распакуйте и запускайте `ТендерАгент.exe` из папки.

Ваши данные хранятся в папке **Документы\ТендерАгент**: настройки, база тендеров,
скачанная документация и готовые пакеты.

## Первый запуск: 3 шага

1. **Реквизиты.** Внесите один раз: наименование, УНП, адрес, банк, руководитель,
   контакты. Там же задаются условия предложения: НДС, наценка или скидка, сроки поставки
   и оплаты, срок действия. Программа подставляет эти данные во все документы.
2. **Прайс.** Выберите файл: Excel (.xlsx/.xls), CSV, выгрузку из 1С в Excel или
   выгрузку обмена 1С с сайтом (`import.xml` / `offers.xml`). Колонки «Наименование»
   и «Цена» программа находит сама, их можно поправить вручную. Внизу вкладки есть поле
   «Проверить поиск по прайсу»: введите название, как его пишет заказчик, и увидите,
   что программа найдёт.
3. **Что ищем.** Укажите ключевые слова, коды ОКРБ (можно только начало кода, например
   `17.12`) и минус-слова. Там же задаются критерии «тендер нам подходит» и интервал
   проверки.

После этого на вкладке «Тендеры» нажмите **«Запустить мониторинг»**.

## Как работает

1. **Поиск.** Раз в заданный интервал программа проверяет три площадки по каждому
   ключевому слову и коду ОКРБ. Новые тендеры появляются в таблице.
2. **Сверка.** Программа скачивает документацию и распаковывает архивы. Затем находит
   спецификацию: позиции, количество, единицы измерения. Каждая позиция сравнивается
   с прайсом.
3. **Решение.** Тендер получает отметку «Подходит», если:
   - в прайсе нашлась нужная доля позиций (по умолчанию 60 %);
   - наша сумма с НДС не выше ориентировочной стоимости.

   Подходящие тендеры выделяются зелёным, программа показывает уведомление.
4. **Карточка тендера** открывается двойным щелчком. В ней:
   - позиции заказчика рядом с товарами из прайса;
   - жёлтым отмечены сомнительные совпадения, красным — товары, которых нет в прайсе;
   - двойной щелчок по товару открывает выбор другого товара, выбор запоминается;
   - цену и количество можно поправить прямо в таблице;
   - галочка «В предложение» включает или исключает позицию.
5. **«Подготовить пакет документов»** создаёт две папки.
   - `Для подачи`:
     - **форма предложения заказчика**, заполненная только позициями, которые
       участвуют в тендере, с вашими реквизитами;
     - другие формы и приложения заказчика с подставленными реквизитами;
     - сопроводительное письмо;
     - сведения об участнике;
     - опись документов.
   - `Для проверки`:
     - чек-лист: что проверить, каких позиций нет в прайсе, какие документы
       упоминает заказчик (сертификаты, выписки и т. п.), условия из документации;
     - сравнение с прайсом (Excel);
     - предложение в виде таблицы.
6. **Подача.** Вы проверяете документы, подписываете их ЭЦП и подаёте на площадке.
   Затем отметьте в карточке «Подан».

Если в документации нет заполняемой формы (.docx или .xlsx), программа составит
ценовое предложение по стандартному образцу. Старые файлы .doc программа переводит
в .docx сама, если на компьютере установлен Microsoft Word. Для архивов .rar и .7z нужен
бесплатный 7-Zip.

## Если тендер найден вручную

- **«+ По ссылке»** — вставьте адрес страницы процедуры.
- **«+ Из папки с документами»** — если документацию вы скачали сами. Программа сверит
  её с прайсом и заполнит формы так же, как при автоматическом поиске.

## Если площадка изменила сайт

На вкладке «Что ищем» нажмите **«Проверить доступ к площадкам»**. В журнале будет
видно, что программа нашла на каждой площадке. Копии страниц сохраняются в папке
`Документы\ТендерАгент\Диагностика`. Если тендеры не находятся, пришлите эти файлы
разработчику. Адреса поиска хранятся в `sites.json`, их можно поправить без
переустановки программы.

## Для разработчика

```
cd tender-agent
pip install -r requirements.txt
python main.py           # запуск
python -m pytest -q      # тесты
pyinstaller TenderAgent.spec   # сборка .exe (на Windows)
```

Сборку `.exe` выполняет GitHub Actions (`.github/workflows/tender-agent-windows.yml`)
при каждом изменении в папке `tender-agent/`. Готовый файл выкладывается в Releases.

Структура:
- `tenderagent/sites/` — площадки: поиск, разбор карточек, ссылки на документы (`sites.json`);
- `tenderagent/pricelist.py` — чтение прайса (Excel, CSV, CommerceML из 1С);
- `tenderagent/matching.py` — сопоставление позиций с прайсом без интернета;
- `tenderagent/docs/` — разбор документации, заполнение форм заказчика, генерация документов;
- `tenderagent/pipeline.py` — цепочка «поиск → сверка → пакет»;
- `tenderagent/gui/` — окно программы (PySide6).
