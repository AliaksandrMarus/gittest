# lighton.by — сайт автомойки и детейлинг-центра «Лайт Он»

Статический многостраничный сайт на Astro. Бобруйск, Минская ул., 123, корп. 8.

## Запуск

```bash
npm install
npm run dev      # локальная разработка, http://localhost:4321
npm run build    # сборка в dist/
npm run preview  # посмотреть собранный сайт
```

Нужен Node 18 или новее.

## Что где лежит

| Путь | Что это |
|---|---|
| `src/config/site.ts` | **Главный файл настроек.** Телефон, адрес, график, мессенджеры, эндпоинт форм, счётчики. Всё остальное читает значения отсюда. |
| `src/content/services/*.md` | Девять услуг: тексты, цены, этапы работ, FAQ. Один файл — одна страница. |
| `src/layouts/` | `Base.astro` — общий каркас и JSON-LD. |
| `src/components/` | Шапка, подвал, формы, анимация фона, кнопки быстрого вызова. |
| `src/pages/` | Страницы сайта. Имя файла = адрес страницы. |
| `public/api/lead.php` | Обработчик заявок для хостинга с PHP. |
| `public/.htaccess` | 301-редиректы со старых адресов, кэширование, заголовки безопасности. |

## Как поменять цену

Цены живут только во frontmatter услуг. Например, в `src/content/services/avtomoyka.md`:

```yaml
price: 15
priceMax: 25
priceNote: "в зависимости от программы"
```

Одна правка — и новая цена появляется в карточке услуги, в сводном прайсе,
в выпадающем списке формы и в разметке для поисковиков. Разойтись они не могут
физически: источник один.

Для услуги без фиксированной цены ставится `price: null` — на сайте появится
«По запросу».

## Как добавить услугу

1. Создайте `src/content/services/nazvanie-uslugi.md` по образцу любого
   существующего файла. Имя файла станет адресом: `/uslugi/nazvanie-uslugi/`.
2. Заполните frontmatter. Обязательные поля проверяются при сборке — если
   что-то забыто, `npm run build` скажет об этом с указанием поля.
3. Иконка берётся из набора в `src/components/Icon.astro`
   (`droplet`, `engine`, `shield`, `film`, `headlight`, `sofa`, `sparkle`).

Страница, карточка на главной, строка в прайсе, пункт в подвале и запись
в `sitemap.xml` создадутся сами.

## Приём заявок с форм

Форма отправляет данные на адрес из константы `FORM_ENDPOINT`
в `src/config/site.ts`. Поддерживаются три сценария.

### Вариант 1. Хостинг с PHP (по умолчанию)

```ts
export const FORM_ENDPOINT = '/api/lead.php';
```

После загрузки сайта на хостинг:

1. Скопируйте `public/api/config.local.php.example` в `config.local.php`
   рядом с `lead.php` на сервере.
2. Впишите почту, куда слать заявки.
3. По желанию добавьте токен Telegram-бота и `chat_id` — заявка будет
   дублироваться в мессенджер.

`config.local.php` добавлен в `.gitignore`, а `.htaccess` закрывает к нему
доступ снаружи: токен не попадёт ни в репозиторий, ни в код страницы.

Если письмо не ушло и Telegram не настроен, заявка всё равно не теряется —
она пишется в `public/api/leads.log`, а посетитель видит просьбу позвонить.

### Вариант 2. Внешний сервис, без PHP

Подходит для GitHub Pages и Netlify. Заведите форму в Web3Forms, Formspree
или подобном сервисе и укажите:

```ts
export const FORM_ENDPOINT = 'https://api.web3forms.com/submit';
export const FORM_ACCESS_KEY = 'ваш-ключ';
```

### Вариант 3. Ничего не подключено

```ts
export const FORM_ENDPOINT = '';
```

Форма не будет притворяться рабочей: вместо неё появится блок с телефоном,
почтой и кнопками мессенджеров. Заявки не теряются молча.

## Аналитика

В `src/config/site.ts`:

```ts
export const analytics = {
  yandexMetrika: '12345678',   // номер счётчика
  ga4: 'G-XXXXXXXXXX',         // идентификатор потока
};
```

Пустая строка — счётчик не подключается вообще. Оба скрипта загружаются
в простое браузера, поэтому не портят показатели скорости.

Цели настраиваются в интерфейсе Метрики по событиям, которые сайт отправляет
сам: `lead_sent` (отправлена заявка) и `phone_click` (клик по телефону).

## Деплой

### Обычный хостинг

Загрузите содержимое `dist/` в корень сайта вместе с `.htaccess`. PHP-обработчик
попадёт туда автоматически: файлы из `public/` копируются в `dist/` при сборке.

### Netlify / Cloudflare Pages

Команда сборки `npm run build`, каталог публикации `dist`. Редиректы подхватятся
из `public/_redirects`. PHP там не работает — используйте вариант 2 для форм.

## После первого деплоя

- [ ] Подставить настоящие фотографии — список в [ASSETS.md](./ASSETS.md)
- [ ] Указать УНП в `site.unp` (обязателен в подвале для юрлица)
- [ ] Подключить приём заявок и проверить, что письмо доходит
- [ ] Вписать номер Яндекс.Метрики и создать цели `lead_sent`, `phone_click`
- [ ] Добавить сайт в Яндекс.Вебмастер и Google Search Console,
      файл подтверждения положить в `public/`
- [ ] Отправить `https://lighton.by/sitemap-index.xml` в обе панели
- [ ] Проверить, что старые адреса (`/services/`, `/contact/`) отдают 301
- [ ] Сверить прайс на сайте с карточкой на Яндекс.Картах — они должны совпадать

## Технические решения

**Почему Astro и статика.** Сайт из семнадцати страниц не нуждается в базе
данных и серверном рендеринге. Статика грузится мгновенно, ложится на любой
хостинг и не ломается от обновления плагинов — в отличие от WordPress,
на котором сайт был раньше.

**Почему шрифт лежит рядом с сайтом.** Подключение Google Fonts — это лишний
DNS-запрос, лишнее соединение и зависимость от доступности стороннего домена.
Файлы лежат в `public/fonts/`, кириллица и латиница разделены по `unicode-range`,
поэтому браузер скачивает только нужное.

**Почему карта грузится по клику.** Виджет Яндекс.Карт тянет около мегабайта
скриптов и ставит сторонние куки. До нажатия кнопки на странице стоит статичная
карточка с адресом.

**Почему рейтинг не размечен как AggregateRating.** Разметка агрегированного
рейтинга допустима только для отзывов, собранных на самом сайте. Проставлять
туда оценки с Яндекс.Карт — нарушение правил Google, за которое снимают
расширенные сниппеты целиком. Рейтинг показан визуально со ссылкой на источник.
