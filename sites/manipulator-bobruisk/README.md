# manipulator-bobruisk.by

Сайт услуг крана-манипулятора и мини-экскаватора в Бобруйске. Astro, статическая сборка + PHP-обработчик заявок.

## Где что править

- **Контакты, цены, характеристики техники, Метрика** — `src/config/site.ts`. Всё остальное подтягивается оттуда.
- **Тексты услуг** — `src/content/services/*.md` (одна услуга = один файл = одна страница).
- **Фото** — `src/assets/photos/`. Список нужных имён — в `ASSETS.md`. Положили файл с нужным именем — он появился на сайте вместо заглушки.

## Сборка

```bash
npm install
npm run build      # результат в dist/
```

## Выкладка на хостинг с PHP (текущий хостинг WordPress подойдёт)

1. Сделайте резервную копию старого сайта.
2. Залейте содержимое `dist/` в корень сайта (вместе со скрытым `.htaccess`).
3. Скопируйте `dist/api/config.local.php.example` в `api/config.local.php` на сервере и заполните:
   почту и/или Telegram-бота для заявок. Без этого заявки пишутся только в `api/leads.log`.
4. Проверьте форму: отправьте тестовую заявку.
5. Добавьте сайт в Яндекс.Вебмастер и Google Search Console, отправьте `https://manipulator-bobruisk.by/sitemap-index.xml`.
6. Счётчик Яндекс.Метрики 103817808 уже подключён. Создайте в Метрике цели (см. SEO.md).

## Что уже есть для SEO

- Отдельная страница под каждый запрос: манипулятор, мини-экскаватор и 8 услуг.
- Уникальные title и description, canonical, Open Graph, sitemap.xml, robots.txt.
- Разметка Schema.org: LocalBusiness (24/7, зона обслуживания), Service, FAQPage, BreadcrumbList.
- Картинки в AVIF/WebP с размерами, шрифты локально, без тяжёлых библиотек.
