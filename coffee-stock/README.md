# Учёт кофейного автомата

Программа для Windows: считает расход ингредиентов по рецептам на основе
ежедневных продаж, сама приходует отсканированные PDF-накладные и показывает
остатки, отчёты и прогноз — на сколько дней хватит запасов.

## Установка

1. Скачайте `CoffeeStock.exe`: на GitHub откройте вкладку **Actions** →
   «Учёт кофейного автомата — сборка CoffeeStock.exe» → последний успешный
   запуск → **Artifacts** → `CoffeeStock`.
2. Создайте папку, например `C:\Кофе`, и положите туда `CoffeeStock.exe`.
3. Запустите. Рядом с программой появятся:

| Что | Зачем |
|---|---|
| `Продажи.xlsx` | сюда каждый день вписываются продажи |
| `Накладные\Входящие` | сюда сканируются накладные в PDF |
| `Накладные\Обработанные` | распознанные накладные (программа переносит сама) |
| `Накладные\Ошибки` | накладные, которые не удалось прочитать |
| `coffee.db` | вся база. **Резервная копия — просто копия этого файла** |

## Первый запуск

1. **Рецепты.** На вкладке «Рецепты» уже есть пример: эспрессо, американо,
   капучино, латте, горячий шоколад. Поправьте нормы на одну порцию под
   настройки своего автомата, добавьте свои напитки и ингредиенты
   (крышки, сливки, чай и т.д.). Единицы: г, мл или шт. «Мин. запас» —
   ниже этого остатка строка станет красной.
2. **Начальные остатки.** «Остатки» → «Инвентаризация (факт. остаток)…» —
   введите, сколько каждого ингредиента есть сейчас.
3. **Распознавание сканов.** «Настройки» → «Ключ Claude API». Без ключа
   программа читает только PDF с текстовым слоем (сохранённые из учётной
   программы поставщика). Сканы-картинки читает только Claude. Ключ
   выдаётся на console.anthropic.com, одна накладная стоит несколько центов.

## Каждый день

**Продажи.** Откройте `Продажи.xlsx` (кнопка «Открыть файл продаж»), впишите
количество каждого напитка за день в строку с датой и сохраните. Программа
сама заметит изменения и спишет ингредиенты по рецептам. Пустые строки
пропускаются, а повторное сохранение того же дня ничего не задваивает:
цифры за день просто заменяются.

**Накладные.** Отсканируйте накладную в PDF в папку `Накладные\Входящие`
(или нажмите «Выбрать PDF вручную…»). Каждые 10 секунд программа:

- распознаёт номер, дату, поставщика и строки «наименование — количество — единица»;
- сопоставляет строки с ингредиентами и переводит единицы (кг → г, л → мл);
- если всё понятно, сразу проводит приход и переносит файл в «Обработанные»;
- если встретился незнакомый товар (например, «Мешалки деревянные, уп»),
  накладная получит статус «Нужна проверка». Выберите для строки
  ингредиент и коэффициент («1 уп = 100 шт»), либо «Не учитывать» для
  доставки и услуг, и нажмите «Провести». **Сопоставление запоминается** —
  следующая такая накладная проведётся сама.

Тот же файл или повторный скан той же накладной (тот же номер, дата и
поставщик) второй раз не приходуется. Ошибочно проведённую накладную можно
«Отменить проведение», исправить и провести снова.

## Отчёты

Вкладка «Отчёты»: выберите период и отчёт.

- **Продажи по видам напитков** — сколько продано, в среднем в день, доля;
- **Продажи по дням** — таблица «дата × напиток»;
- **Приход** — все поступления с номерами накладных;
- **Движение ингредиентов** — остаток на начало, приход, расход, корректировки, остаток на конец;
- **Прогноз** — средний расход в день и на сколько дней хватит остатков.

«Экспорт в Excel…» сохраняет все отчёты за период в один файл, каждый на своём листе.

На вкладке «Остатки» всегда виден текущий остаток, прогноз «закончится
примерно» и сколько порций каждого напитка ещё можно приготовить. Прогноз
считается по среднему расходу за последние 14 дней с продажами (меняется в
«Настройках»).

## Для разработчика

```
cd coffee-stock
pip install -r requirements-dev.txt
python -m pytest
python run.py            # данные будут в coffee-stock/data
```

Рабочую папку можно задать переменной `COFFEE_STOCK_HOME`. Сборка exe —
`.github/workflows/coffee-stock.yml` (PyInstaller на windows-latest).
