# Учёт кофейного автомата

Программа для Windows: считает расход ингредиентов по рецептам на основе
ежедневных продаж и выручку по ценам напитков. Отсканированные PDF-накладные
она приходует сама, без интернета. Показывает остатки, отчёты и прогноз, на
сколько дней хватит запасов.

## Установка

1. Скачайте программу один раз со страницы выпусков:
   https://github.com/AliaksandrMarus/gittest/releases — файл `CoffeeStock.zip`
   у самого нового выпуска «Учёт кофейного автомата 1.0.N».
2. Распакуйте архив в папку, например `C:\Кофе\CoffeeStock`, и запустите
   `CoffeeStock.exe`. В архиве уже есть Tesseract для распознавания сканов,
   отдельно ставить ничего не нужно.
3. Рядом с программой появятся:

| Что | Зачем |
|---|---|
| `Продажи.xlsx` | сюда каждый день вписываются продажи |
| `Накладные\Входящие` | сюда сканируются накладные в PDF |
| `Накладные\Обработанные` | распознанные накладные (программа переносит сама) |
| `Накладные\Ошибки` | накладные, которые не удалось прочитать |
| `coffee.db` | вся база. **Резервная копия — просто копия этого файла** |

## Обновления — без переустановки

При запуске программа проверяет, нет ли новой версии (нужен интернет). Если
есть, она покажет, что изменилось, и предложит обновиться. Нажмите «Да»:
программа сама скачает архив, закроется, заменит свои файлы и откроется уже
новой версией. База, файл продаж и накладные не трогаются, а перед
обновлением база дополнительно копируется в `coffee.db.до-обновления-….bak`.

Проверить вручную: «Настройки» → «Проверить обновления». Там же можно
отключить автоматическую проверку при запуске. Номер версии виден в заголовке
окна.

## Данные ДС №152 уже внутри

При первом запуске (или при обновлении, если в программе ещё нет ни накладных,
ни продаж) программа сама заносит начальные данные автомата ДС №152:

- накладную ТТН ИД 4692066 от 17.06.2026 (ООО «ПРОКСИМАВЕСТ») — остаток на 01.07.2026;
- рецептуру и цены шести напитков;
- продажи: июль — итогом месяца на 31.07, август–21 октября — по дням;
- инвентаризацию на 21.10.2026: палочки для размешивания закончились (остаток 0).

Старый файл продаж, если был, сохраняется как «Продажи (до переноса данных).xlsx».

## Первый запуск

1. **Рецепты и цены.** Вкладка «Рецепты и цены»: у каждого напитка укажите
   цену порции и расход ингредиентов на одну порцию. Добавьте свои напитки и
   ингредиенты (крышки, сливки, чай и т.д.). Единицы — г, мл или шт.
   «Мин. запас»: если остаток опустится ниже него, строка станет красной.
2. **Начальные остатки.** «Остатки» → «Инвентаризация…» — введите, сколько
   каждого ингредиента есть сейчас.

## Каждый день

**Продажи.** Откройте `Продажи.xlsx`, впишите количество каждого напитка за
день в строку с датой и сохраните. Программа сама заметит изменения, спишет
ингредиенты по рецептам и посчитает выручку. Цена фиксируется на день продажи:
если поднять цену, прошлые дни останутся по старой.

**Накладные.** Отсканируйте накладную в PDF в папку `Накладные\Входящие`
или нажмите «Выбрать PDF…». Программа распознаёт:

- реквизиты: дату, номер, поставщика;
- таблицу: наименование, единицу, количество, цену, НДС, сумму с НДС.

PDF с текстом (от поставщика или «PDF с поиском» со сканера) читается
напрямую. Скан-картинку распознаёт встроенный Tesseract: линии таблицы
стираются, текст читается, колонки восстанавливаются по шапке.

Строки сопоставляются с ингредиентами, единицы переводятся (кг → г, л → мл).
Если всё понятно, приход проводится сразу.

**Ручная правка.** Если накладная распознана неточно или встретился
незнакомый товар, она получает статус «Нужна проверка». Откройте её
(«Редактировать…» или двойной щелчок). В карточке можно:

- исправить дату, номер, поставщика и любую строку;
- добавить или удалить строку;
- выбрать для строки ингредиент и коэффициент («1 уп = 100 шт»);
- отметить доставку и услуги как «Не учитывать».

Затем нажмите «Сохранить и провести». **Сопоставление запоминается**, и в
следующий раз такая строка проведётся сама. Можно править и уже проведённую
накладную: приход пересчитается автоматически. Если накладная совсем не
читается, заведите её кнопкой «Новая накладная вручную…».

Повторный скан той же накладной (тот же номер, дата и поставщик) второй раз
не приходуется.

## Остатки, выручка и отчёты

На вкладке «Остатки» карточки показывают:

- выручку за последний день;
- выручку за месяц;
- сколько порций продано за месяц;
- сколько ингредиентов на исходе.

Ниже — остаток каждого ингредиента, расход в день, на сколько дней хватит и
сколько порций каждого напитка ещё можно приготовить.

Вкладка «Отчёты»: выберите период и отчёт.

- **Продажи по видам напитков** — количество, выручка, средняя цена, доля в выручке и общий итог;
- **Продажи по дням** — таблица «дата × напиток» с выручкой за каждый день;
- **Накладные (приход)** — дата, №, поставщик, наименование, количество, цена, НДС, с НДС и итоги;
- **Движение ингредиентов** — остаток на начало, приход, расход, корректировки, остаток на конец;
- **Прогноз** — средний расход в день и на сколько дней хватит остатков.

«Экспорт в Excel…» сохраняет все отчёты за период в один файл, каждый на своём листе.

## Для разработчика

```
cd coffee-stock
pip install -r requirements-dev.txt
python -m pytest
python run.py            # данные будут в coffee-stock/data
```

Для распознавания сканов нужен Tesseract с русским языком (`apt install
tesseract-ocr-rus` или установщик UB Mannheim для Windows). Рабочую папку
можно задать переменной `COFFEE_STOCK_HOME`. Сборка —
`.github/workflows/coffee-stock.yml` (PyInstaller и Tesseract на windows-latest):
каждая успешная сборка публикуется выпуском `coffee-stock-v1.0.N` с архивом
`CoffeeStock.zip`, его и находит автообновление (`coffee_stock/updater.py`).
