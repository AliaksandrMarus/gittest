# Фотографии для сайта

**Сейчас на месте снимков — сгенерированные демо-иллюстрации, а не
фотографии.** Скачать настоящие снимки из среды разработки было нельзя
(сетевая политика блокирует все фотобанки и медиабиблиотеку старого сайта),
поэтому вместо пунктирных заглушек нарисованы фирменные заставки: тот же
тёмный фон и циановый луч, что у фоновой анимации сайта, с крупной иконкой
услуги по центру — `scripts/gen-demo-visuals.mjs`. Это не имитация фото:
иллюстрация не претендует быть доказательством реальной работы, поэтому
даже в галерее «Наши работы» и в парах «было/стало» она не обманывает
посетителя так, как обманул бы стоковый снимок чужой машины.

**Как только файл с настоящим именем появляется в `src/assets/`, он сам
заменяет иллюстрацию на сайте.** Достаточно загрузить фото с тем же именем
поверх — компонент `Photo` не различает, откуда взялся файл, лишь бы имя
совпадало. Список точных имён — в таблицах ниже. Полностью пересоздать все
23 иллюстрации заново: `node scripts/gen-demo-visuals.mjs`.

## Откуда взять снимки

### 1. Медиабиблиотека старого сайта — самое полное

В `wp-content/uploads/` лежат оригиналы всего, что было на lighton.by. Три
способа забрать, по убыванию надёжности:

**Файловый менеджер хостинга или FTP.** Скачать папку `wp-content/uploads/`
целиком. Работает всегда, ничего не требует от WordPress.

**Автоматически, скриптом.** Публичный REST-эндпоинт WordPress отдаёт список
всех файлов без авторизации:

```bash
node scripts/fetch-photos.mjs --wp
```

Скрипт обойдёт `https://lighton.by/wp-json/wp/v2/media` постранично и сложит
всё в `src/assets/wp/`. Через `/wp-admin/upload.php` так сделать нельзя: туда
нужен вход, и массовой выгрузки файлов там всё равно нет.

**Плагин** вида Export Media Library — собирает библиотеку в один архив.

По сохранённой главной видно, что там искать: слайдер `31.jpg` и `34.jpg`
за декабрь 2025, фотографии услуг с говорящими именами
(`Мойка-мотора-темно-синего-автомобиля.jpg` 1040×1384,
`Темно-синий-автомобиль-моется-на-автомойке-густой-пеной.jpg`,
`Тонировка-черной-пленкой-задних-стекол-темно-синего-автомобиля.jpg`,
`оклейка-темно-синего-автомобиля-антигравийной-пленкой-…jpg`) и серия
`photo_2025-10-21_*`, `photo_2025-12-02_*`.

### 2. Карточка на Яндекс.Картах — 61 снимок

```bash
node scripts/fetch-photos.mjs
```

В скрипт уже зашиты 16 адресов, извлечённых из сохранённой карточки. Остальные
подгружаются отдельным запросом и в сохранённую страницу не попали — чтобы
достать и их, откройте карточку, перейдите на вкладку «Фото», пролистайте
до конца, сохраните страницу и пришлите: адреса извлекаются так же.

Оба источника сразу:

```bash
node scripts/fetch-photos.mjs --all
```

### 3. Стоковые фотографии — только не в работы

В галерею «Наши работы» и в пары «было/стало» стоковые снимки не ставятся.
Чужая машина, выданная за результат работы этой мойки, распознаётся мгновенно:
в комментариях к таким галереям первым делом пишут, что фото из интернета.
Восстановить доверие после этого нельзя, а весь текст сайта построен именно
на нём — «говорим, что вам не нужно», «цены открыты», «переделаем бесплатно».
Заглушка честнее.

Для декоративных мест (фон, общая атмосфера) сток с открытой лицензией
допустим — но к этому стоит возвращаться, когда станет ясно, каких собственных
кадров реально не хватает.

## Куда класть файлы

```
src/assets/
  uslugi/     шапки страниц услуг
  raboty/     галерея и пары «до/после»
  yandex/     промежуточная выгрузка, в репозиторий не идёт
  wp/         промежуточная выгрузка, в репозиторий не идёт
```

## Как снимать, чтобы получилось хорошо

- **Один ракурс на пару «до/после».** Сместилась камера — эффект пропал.
- **Свет из бокса, без вспышки в лоб.** Вспышка убивает глубину мокрого лака.
- **Горизонтальная ориентация**, пропорции близкие к 4:3. Вертикальные кадры
  придётся обрезать, часть работы уйдёт за край.
- **От 1600 px по длинной стороне.** Уменьшить можно, увеличить — нет.
- **JPEG прямо с телефона подойдёт.** Сборка сама сожмёт файл и сделает
  версии в AVIF и WebP с запасным JPEG — вручную ничего оптимизировать не надо.
- **Номера** показывать только с согласия владельца автомобиля.
